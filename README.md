종석(@oa6) 님에게 전달받은 원본 스킬(라라 블로그 스킬, 쇼핑커넥트 스킬)을 **은정 님의 상황(신규 개설 예정, 메인 주제: 연예가 뉴스, 향후 쇼핑커넥트 안착)**에 맞춰 전면 재설계한 전용 집필 체계입니다.

## 📁 저장된 스킬 파일

1. **`entertainment_blog_skill.md` (메인 스킬: 연예가 뉴스 전문 집필)**
   - **신규 블로그 0 to 1 빌드업**: 초기 저품질/어뷰징 위험 없는 롱테일 키워드 선점 전략 (인물관계도, 몇부작, OTT, 원작 결말 등).
   - **네이버 모바일 홈판(연예판/MY피드) 최적화**: 25자 압축 제목 공식, 첫 120자 리드문, 1:1 대표 썸네일, 2~3줄 모바일 호흡.
   - **가독성 극대화 서식 (은정 님 피드백 & 파워블로거 벤치마킹)**:
     - 소제목 **19pt 굵게(Bold)** 적용, 소제목 **앞 2줄 / 뒤 1줄 공백**.
     - 리스트 항목 및 인물 소개 간 **빈 줄 1개씩 삽입**.
     - 인용구 버티컬 바(`|`), 가로 구분선, 네이버 공식 '글감' 카드 위젯 적극 활용.
   - **1인칭 시청자 공감형 문체**: 단순 뉴스 복사·붙여넣기를 탈피해 D.I.A.+ 지수를 높이는 독창적 감상과 묵직한 통찰.

2. **`shopping_connect_entertainment_skill.md` (수익화 스킬: 쇼핑커넥트 연계)**
   - **안착 시기 기준**: 일 방문자 500~1,000명 달성 후 시작 (블로그 C-Rank 보호).
   - **황금 비율**: 순수 연예 리뷰 80% : 쇼핑커넥트 20% (주 1회).
   - **3대 킬러 카테고리**:
     - ① 스타 사복·드라마 착장 (명품 정품 정보 + 3~5만 원대 가성비 데일리 대체재 매칭)
     - ② 예능 속 연예인 살림/주방/인테리어 템 (나혼산, 전참시 등)
     - ③ 스타 다이어트/이너뷰티 꿀템
   - **전환 5원칙 & 6단계 구조**: 시청 순간 트리거 → 가치 환산 → 비교표 → 솔직한 단점 1개 → 자연스러운 위젯 연결.

3. **`travel_connect_entertainment_skill.md` (수익화 스킬: 여행커넥트 연계)**
   - **연계 콘텐츠**: 예능·드라마 속 화제의 숙소/풀빌라, 여행 예능 액티비티 투어, 드라마 촬영지 주말 코스.
   - **핵심 전략**: 명장면 소환 → 정확한 위치/요금 요약 표 → 인생샷 스팟 → 추천 코스 동선 → 여행커넥트 숙소/투어 제휴 연동.

4. **`reference/` (종석 님이 제공해 주신 최신 원본 스킬 참고 폴더)**
   - **`0-lala_blog_skill.md`**: 네이버 모바일 홈판(MY피드) 노출 및 C-Rank 검색 최적화 프레임워크 최신본.
   - **`1-naver_connect_skill.md`**: 쇼핑·여행커넥트 통합 마스터 스킬 (주 3회 요일제 루틴, 구매 링크 최하단 후방 배치 원칙, 6-Block 구조, 1:1 감성 실사 썸네일 가이드).

## 🚀 블로그 운영 3단계 로드맵

| 단계 | 목표 | 주요 콘텐츠 | 쇼핑커넥트 여부 |
| :--- | :--- | :--- | :--- |
| **1단계: 빌드업 (글 1~30개)** | 일 방문자 100~300명, 방송/연예 카테고리 C-Rank 각인 | 드라마/예능 방영 전 프리뷰, 조연 배우 프로필, 촬영지/식당 정보 | **절대 금지 (링크 X)** |
| **2단계: 트렌드 확장 (글 31~80개)** | 일 방문자 500~1,500명, 홈판/스마트블록 유입 | 본방 직후 회차별 결말/복선 리뷰, 커뮤니티 화제 반응 | **준비 단계** |
| **3단계: 수익화 안착 (글 80개 이후)** | 일 방문자 2,000명+, 안정적 어필리에이트 수익 | 월~목: 순수 리뷰 / 금~토: 스타 착장·살림템 큐레이션 | **주 1~2회 집행 (8:2 비율)** |
